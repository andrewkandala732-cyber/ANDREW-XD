## ✨ Features Overview
**ANDREW-XD** ni WhatsApp Bot ya kisasa iliyojengwa na `@whiskeysockets/baileys`

- **Pair Code + QR**: Unganisha kwa njia 2
- **Auto Session**: Inatuma `SESSION_ID` moja kwa moja WhatsApp
- **24/7 Online**: Inafanya kazi Render bila kuzima
- **Lightweight**: Haraka na isitumia MB nyingi
